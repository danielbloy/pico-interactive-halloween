# Halloween 2026

2026 sees the introduction of the new Mark III nodes which are entirely
3D printed and more versatile than both the previous Mark I and Mark II
nodes as they screw together in sections. For the 2026 display, we will
be adding at least 3 nodes and (if time allows) replacing the 3 x Mark I
nodes with Mark III nodes. The current Mark III nodes are all battery powered
for ease of installation and use. A future enhancement is to support USB
power.

The Mark III nodes also come with the entirely new software stack that is
more efficient so only a single Pico is required per box rather than the
2 Picos required in the Mark I and II nodes. We have also prototyped using
Pico 2 and ESP32-S3 boards that are both more powerful and have
significantly more RAM available. The more powerful devices, improved
software stack and improved nodes have opened up a lot of options for
future enhancements to the display.

The new software stack and nodes have taken a significant amount of time
to prepare so there are no major changes to the layout of display, which
remains identical in terms of overall to the 2025 display. We've just
added more stuff. For a description of how the installation area is
arranged and split into "zones", please refer to [layout](./layout.md).
