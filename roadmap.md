# Roadmap

* Support for Raspberry Pi (3A+ and Zero 2W) with `cptkip` and `pico-interactive`
* Add LCD screen support to make projectors for floating eyes.
* Add support for Video out using Pico 2s to drive displays.
* Replace all remaining Mark 1 boxes.
* Replace the Mark 2 boxes.
* Come up with a much better power distribution system for the entire display
  based on mains power distribution to each zone.
* Migrate all primary networking and control to Raspberry Pi devices.
* Coffin that shakes and makes noises
* Boxes that open with eyes
